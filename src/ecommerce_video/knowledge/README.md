# knowledge/ 知识库结构说明

> 知识库 = 静态字典数据（参考数据），JSON 为唯一事实源。
> 人读文档（01/02/05/06 *.md）由 JSON 生成或手工维护并保持同步；程序（批量生成脚本）直接读 JSON。
> 业务数据（商品项目/生成任务/质检记录）不在这里，放 `data/`（SQLite，随批量生成功能建设）。

## 通用字段约定

```json
{
  "id": "唯一标识",
  "category": "适用品类（all=通用）",
  "tags": ["检索标签"],
  "zh": "中文描述",
  "prompt_zh": "中文提示词片段",
  "avoid": "避坑说明",
  "negative": "负面词（可选）",
  "weight": 1
}
```

## 使用约定

1. 改知识 → 改 JSON，不直接改 MD（除非 MD 是手工分析类文档）
2. 每品类一个知识包（category-profiles.json 索引），新品类进来 = 新增一个 profile
3. AI 生成提示词时：读 JSON → 拼装 → 输出；不依赖人读 MD
4. **检索流程：先读 index.json（定位文件）→ 按 retrieval_paths 找到目标文件 → 按 id/tags 取条目，不全量加载**
